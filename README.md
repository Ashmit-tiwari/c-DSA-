# 🚀 CPP-DSA

A collection of **Data Structures and Algorithms** solutions implemented in **C++**, primarily solved on **LeetCode**.

This repository serves as my personal coding journal where I practice problem-solving, strengthen core DSA concepts, and prepare for technical interviews.

## 🎯 Objectives

* Improve problem-solving skills
* Master Data Structures and Algorithms
* Learn multiple approaches to solve problems
* Write clean, efficient, and optimized C++ code
* Prepare for coding interviews and competitive programming

## 💻 Language

* C++

## 📂 Organization

Problems are organized by topic to make navigation simple and to reinforce concept-based learning.

Some of the topics include:

* Arrays

* Stack
* Queue
* Hashing
* Binary Search
* Trees
* Binary Search Trees
* Heap
* Graphs
* Recursion
* Backtracking
* Dynamic Programming
* Greedy Algorithms
* Sliding Window
* Two Pointers
* Bit Manipulation
* Mathematics

## 📖 Solution Format

Each solution follows a consistent structure and may include:

* Problem name
* Approach
* Time Complexity
* Space Complexity
* Clean and well-commented C++ implementation
